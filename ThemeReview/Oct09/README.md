# Screenshot bar drafts

These sixteen Glance-native bar presets have been approved and installed in Randomazzo alongside six earlier references. The canonical saved and bundled presets are in ../../GlanceThemePresets. These files are the original review snapshots.

Each TOML can be previewed with `GLANCE_CONFIG_PATH=<absolute-file> Glance --export-bar <image> --export-width 1600`. Vertical rails accept `--export-height 900`; Ocean Twin has a second panel exported with `--export-bar-name bottom`.

All use Pywal and 14pt or larger text. Battery widgets and wallpaper blur are omitted. Native data replaces Linux-specific integrations. Bluetooth displays connected-device counts. GPU data is unavailable unless supplied by a custom script.

See REPLICATION.md and manifest.json for the reference-to-module map.
